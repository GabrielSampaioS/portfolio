## O que foi feito

- API REST com Node.js, TypeScript, Express e MongoDB seguindo **DDD**, **SOLID** e **Clean Architecture**.
- Arquitetura baseada em **Event Sourcing**.
- Testes **End-to-End**, de **Integração** e **Unitários** com Supertest e Node Test.
- Balanceamento de carga com **Nginx**.
- Pipeline **CI/CD** com GitHub Actions para execução automática de testes.
- Publicação de imagens Docker e deploy automatizado na **AWS Elastic Beanstalk**.
- Autenticação com **JWT** e proteção de rotas.
